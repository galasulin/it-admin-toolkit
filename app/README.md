# ארגז כלים IT

חלון אחד עם 67 כלים לכל עבודת ה-IT היומיומית: אבחון ותיקון תחנות, הקמת מחשבים ושדרוגים, מדפסות, שרתים וגיבויי SQL, Active Directory, Office 365, אבטחה, רשת ודוחות.
כל כלי רץ על המחשב שלך או מרחוק על כל מחשב ושרת בדומיין.

## הפעלה

1. מחלצים את התיקייה למחשב שלך, למשל `C:\IT-Toolkit`.
2. **בפעם הראשונה:** מעתיקים את `config.example.json` ל-`config.json` וממלאים בו את הפרטים האמיתיים (פירוט בהמשך). אם לא עושים את זה, הכלי יוצר את הקובץ לבד מהדוגמה, ומציג באנר עם כפתור שפותח אותו.
3. לחיצה כפולה על `Run.cmd`. מופיעה בקשת הרשאות מנהל (UAC), ואחרי שנייה-שתיים נפתח חלון אפליקציה של Edge.

**אם משהו לא נפתח:** `Run-Classic.cmd` פותח את החלון הקלאסי (WPF), עם אותם כלים בדיוק.

### איך זה בנוי

- **המנוע:** PowerShell שרץ כמנהל ומאזין רק ל-`127.0.0.1`, כלומר רק מהמחשב שלך. כל בקשה צריכה טוקן אקראי שנוצר בכל הפעלה, והשרת דוחה בקשות עם כתובת Host אחרת (הגנה מ-DNS rebinding).
- **החלון:** Edge במצב אפליקציה, בלי שורת כתובת, ולא כמנהל. יש לו פרופיל נפרד ב-`%LOCALAPPDATA%\IT-Toolkit\edge-profile`.
- **סגירה:** סוגרים את החלון, והשרת נסגר לבד אחרי שלוש דקות, אבל רק אם אף כלי לא רץ באותו רגע.
- **הממשק:** React, עם GSAP לרגע הפתיחה ולהופעת התוצאות, Lenis לגלילה רכה, ורכיבים מ-React Bits (רשת הנקודות בכותרת, כרטיסי Spotlight, מספרים רצים וטקסט מנצנץ בזמן הרצה). הגופנים מותקנים מקומית, והכלי עובד גם בלי אינטרנט.
- **קיצורים:** `Ctrl+K` פותח חיפוש מהיר של כל הכלים.

## כללי הבטיחות (קבועים בקוד)

| סימן | סוג | מה קורה |
|---|---|---|
| (ללא) | קריאה בלבד | לא משנה כלום. רץ מיד |
| ✎ | מבצע שינוי | מוצג בדיוק מה יקרה, על איזה יעד ועם אילו פרמטרים. רץ רק אחרי "כן" |
| 🔒 | מידע רגיש | אישור לפני ההצגה, ואישור נוסף לפני שמירה לקובץ |

- **אין מחיקות.** התיקיות של Windows Update ו-Teams מקבלות שם חדש. עובד שעוזב מושבת ולא נמחק, והקבוצות שלו רק מוצגות. עבודות הדפסה תקועות מועברות לתיקיית גיבוי.
- **החריג היחיד:** "ניקוי קבצים זמניים" מוחק, ורק קבצים זמניים ישנים. זה כתוב במפורש בחלון האישור.
- **לוג:** כל הרצה נרשמת ב-`logs\toolkit-YYYY-MM.log`: מי, מתי, איזה כלי, על איזה יעד, עם אילו פרמטרים ומה התוצאה. **תוכן התוצאות לא נרשם**, כך שסיסמאות ומפתחות לא נשמרים בלוג.
- **סיסמאות:** איפוס סיסמה ומשתמש חדש מקבלים סיסמה זמנית אקראית שמוצגת פעם אחת, עם חובת החלפה בכניסה הראשונה.

## config.json

| שדה | מה זה |
|---|---|
| `OrgName` | שם שיופיע בכותרת |
| `DomainController` | שם ה-DC. כלי ה-AD רצים עליו, כך שלא צריך RSAT במחשב שלך |
| `Servers` | רשימת שרתים. ב-`SqlInstances` כותבים `.` ל-Default Instance או `.\SHEM` ל-Named Instance. ב-`SqlDatabases` כותבים את המסדים שחובה לגבות. מסד שלא מופיע ברשימה יסומן "לא נדרש" ולא כקריטי |
| `Targets` | מחשבים נוספים שיופיעו ברשימת היעדים |
| `BackupFolders` | תיקיות שיתוף עם קבצי גיבוי. צ'קליסט הבוקר בודק שיש בהן קובץ חדש מ-`MaxAgeHours` |
| `StandardApps` | מזהי winget לתוכנות של כל מחשב חדש |
| `VirusTotalApiKey` | מפתח חינמי מ-virustotal.com, לכלי VirusTotal |
| `DiskWarnPercent` / `DiskCriticalPercent` | ספים של מקום פנוי |
| `SqlFullBackupMaxHours` | כמה שעות מותר בלי גיבוי Full/Diff |

`config.json` נמצא ב-`.gitignore` ולא יעלה ל-GitHub.

## דרישות להרצה מרחוק

הרצה מרחוק משתמשת ב-WinRM, הדרך הרשמית של PowerShell.
- **שרתים:** בדרך כלל מופעל כבר.
- **תחנות:** מפעילים פעם אחת בכל הדומיין דרך GPO:
  `Computer Configuration > Policies > Administrative Templates > Windows Components > Windows Remote Management (WinRM) > WinRM Service > Allow remote server management through WinRM`
  ובנוסף פותחים בחומת האש את חוק `Windows Remote Management (HTTP-In)`.
  או על מחשב בודד, כמנהל: `Enable-PSRemoting -Force`.

## Office 365

כלי Office 365 נפתחים בחלון PowerShell נפרד, כי ההתחברות שם אינטראקטיבית. בהרצה הראשונה מותקנים המודולים `ExchangeOnlineManagement` ו-`Microsoft.Graph.Authentication`, למשתמש שלך בלבד.

## דוח בוקר אוטומטי

הכלי "הפעלת דוח בוקר אוטומטי" יוצר משימה מתוזמנת במחשב שלך לימים א'-ה'. הדוח נשמר ב-`reports\daily-YYYYMMDD.html` ונפתח לבד, ואם יש בעיות מוצגת התראה.
אפשר גם להריץ ידנית: `Run-DailyReport.ps1`.

## הוספת כלי חדש

1. כותבים סקריפט ב-`tools\<תיקייה>\` שמתחיל ב-`param([hashtable]$P = @{})` ומחזיר אובייקטים. עמודה בשם `מצב` עם `תקין` / `אזהרה` / `קריטי` צובעת את השורות.
2. הסקריפט חייב להיות עצמאי, בלי dot-source לקבצים אחרים, כי הוא נשלח כמו שהוא למחשב המרוחק.
3. מוסיפים רשומה ב-`catalog.json`.
4. שומרים את הקובץ ב-UTF-8 **עם BOM**, אחרת העברית נשברת ב-Windows PowerShell 5.1.

## מבנה

```
Run.cmd                  הפעלה (ממשק Web בחלון Edge)
Run-Classic.cmd          הפעלה בחלון הקלאסי (WPF)
Start-Toolkit.ps1        מפעיל ושרת מקומי
Start-Classic.ps1        החלון הקלאסי
Run-DailyReport.ps1      דוח בוקר בלי חלון
catalog.json             רשימת הכלים, התיאורים והפרמטרים
config.example.json      דוגמת הגדרות
modules\Toolkit.Core.psm1  הרצה מקומית ומרחוק, לוג, ייצוא
web\                     הממשק הבנוי (מה שרץ בפועל)
ui-src\                  קוד המקור של הממשק (React)
ui\MainWindow.xaml       עיצוב החלון הקלאסי
tools\...                הכלים עצמם, לפי קטגוריות
```

### שינוי בממשק

צריך Node.js. בתיקייה `ui-src` מריצים `npm install` ואז `npm run build`. התוצאה נכתבת ל-`web\`.
